01 / PROJECT OVERVIEW

Wireless access, reliably connected.

This project demonstrates a small wireless local area network (WLAN) in which multiple laptop clients connect to a central wireless router and communicate with a server over an IP network.

⌁

Objective

Build and verify a wireless LAN using IEEE 802.11, secure client access, automatic addressing, and end-to-end connectivity.

◈

Tools & platform

Cisco Packet Tracer 9.0.1, WRT300N wireless router, Laptop-PT clients, and Server-PT.

02 / NETWORK ARCHITECTURE

One access point.
Four wireless clients.

The WRT300N acts as the central access point. Four laptops associate with the wireless network, while the server is connected to the router through a wired Ethernet link.

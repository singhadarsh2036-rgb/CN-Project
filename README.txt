Project: Design and Simulation of a Wireless LAN Using IEEE 802.11
Student: Adarsh Kumar | Registration: 24BIT0101 | Course: BITE403P

DEPLOY ON VERCEL
1. Extract this ZIP.
2. Create a new GitHub repository named CN-Project.
3. Upload all files and the assets folder (keep the same folder structure).
4. In Vercel, choose Add New -> Project, import CN-Project from GitHub.
5. Framework Preset: Other. Build Command: leave blank. Output Directory: . (or leave default).
6. Click Deploy.

This is a static project demonstration website. The actual network simulation is the separate Cisco Packet Tracer file CN_Project.pkt.
The gallery contains screenshots captured from the Packet Tracer simulation.
